# Domain Docs

## 探索代码前

本仓库采用 single-context：

- 读取根目录 `CONTEXT.md`。
- 读取 `docs/adr/` 中与当前工作相关的 ADR。

文件不存在时静默继续。术语或决策实际明确后，由
`domain-modeling` 技能按需创建，不预先生成占位文档。

## 使用领域词汇

在 issue 标题、重构建议、假设和测试名称中，使用
`CONTEXT.md` 定义的术语，避免其明确排除的同义词。

需要的概念尚未收录时，先判断是否误用了项目之外的语言；
确有缺口则记录为后续领域建模事项。

## ADR 冲突

建议与现有 ADR 冲突时，明确指出对应 ADR 及重新讨论的理由，
而非静默覆盖。
