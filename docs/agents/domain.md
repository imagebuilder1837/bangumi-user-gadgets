# 领域文档

## 探索代码前

本仓库采用 single-context：

- 读取根目录 `CONTEXT.md`。
- 读取 `docs/adr/` 中与当前任务相关的 ADR。

文件不存在时静默继续。领域术语或决策明确后按需使用 domain-modeling 技能维护，不预建 CONTEXT-MAP。

## 维护职责

`CONTEXT.md` 仅为领域词汇表，不承载功能规格、工程约束、实现细节或待办。在 issue、假设、测试和建议中使用其术语；概念缺失时先检查是否误用了其他项目语言，确有缺口再做领域建模。

ADR 仅记录有真实取舍、难以逆转且缺少背景就令人意外的决定，其他约定留在对应指南或规格。建议与现有 ADR 冲突时，指出具体文档及重新讨论的理由，不静默覆盖。

功能规格与其他文档的权威边界见 [开发指南](../development.md)。
