## 范围与身份

展示的是目标用户**开发的组件**，不是作者启用了哪些组件。集合仅来自当前 origin 的格纳库主列表响应；不补全私有、下架或未展示作品，不抓详情／源码，不设备用数据源。空作者结果不能声称该用户从未开发过组件。

目标由页面路径与原生日志导航共同确认，比较解码后的用户标识；格纳库作者按该标识精确匹配。昵称仅展示，用户名与数字 UID 不归并，不查询别名、不回退当前查看者，也不从简介推断协作者。这会漏掉以另一种标识展示的作品，是已接受的边界。

支持三个 Bangumi HTTPS 域的个人主页及日志、目录、好友、反向好友、时间胶囊、人物、小组、维基分区和相应子路径，以及五类收藏的合法状态页；天窗、未知分区／状态不纳入。metadata 匹配范围不是入口授权。

唯一虚拟路由是 `#gadgets`。搜索、分类、标签、排序不改 pathname/query，也不写入 hash 或新增历史项。普通页面初始化只插入口，不预取格纳库；首次读取必须同时满足有效路由与安全挂载条件。

## 宿主所有权与共存

接管是可逆的 hide + sibling：保留个人页头、一级导航与 footer，不移动、克隆或重建宿主正文。入口资格与正文可靠边界分开校验；缺少可选昵称不应阻断，无法确认唯一可靠正文／footer 边界则不接管并说明阻断原因。

恢复不是回写快照。退出只能恢复仍归本组件所有的隐藏标记、导航 focus、标题及适用焦点／滚动；外部修改优先，已删节点不复活，后来转移的键盘焦点不抢回，原生锚点优先。标题使用“昵称 的组件”，无昵称时用用户标识，不附站点后缀。

自有节点、标记、ID、控件分组和 CSS 不借用宿主 ID。只隐藏进入时可靠捕获的二级导航，不批量处理后来加入的未知节点；不在活动期监控宿主结构以争抢或自动修复。

与独立用户帖子组件共存的时序不能简化：Window 的 hashchange 捕获阶段同步退出，进入安排到**下一任务**，届时重核路由与代次；微任务不等价。初始化与同 hash 挂载重试也走此边界，不建立共享运行时。正常重复点击不重抓、不重建。

## 数据完整性与降级

只使用当前域 `/dev/garage` 的普通同源读取；不同域不共享登录态、数据或动作链接。主列表是一份完整集合，推荐区不重复计入，不实现抓取或展示分页，也不以曾观察到的固定卡片数证明完整性。

归属关键字段缺失、验证页、分页迹象或结构不完整必须报读取错误，不能跳过坏卡片后冒充完整集合。相同 ID 的一致内容保留首次项，关键内容冲突报错。排序字段缺失保留卡片，不猜时间、人数或时区。

分类配置是可降级的附属数据：失效不丢有效卡片，仍允许搜索与排序，并说明分类暂不可用；不能把配置失效解释成全部“未分类”。缺少操作按钮也不影响浏览，不推断启用状态、不补造动作链接。

响应脚本不执行。远端文本与搜索词不作为可执行 HTML 拼接；简介保留安全链接和显式换行，普通源码空白按 HTML 自然折叠。动作链接只能来自当次响应，并约束到当前域、对应组件和合法动作，不生成或复用保存页令牌。

## 同文档会话

任务、数据、错误、搜索、分类、标签和各排序方向按已确认目标隔离，生命周期长于视图。退出只清视图资源，不取消已开始读取或已提交动作；重入复用同一任务与状态。后台完成只更新所属状态，发布 UI 时重核当前路由和会话，不能重开视图、抢焦点、滚动或在宿主页弹提示。

不设应用层持久缓存、轮询或刷新按钮。成功数据在同文档内不自动刷新，重新读取需整页刷新；关闭或重开文档不保证任务继续。

读取每次尝试超时 15 秒；网络异常、超时、HTTP 408／5xx 最多额外重试两次，间隔 1 秒、2 秒。其他普通 4xx 与解析／结构失败不自动重试。429 按有效 Retry-After 冷却，否则 60 秒；退出重入不清冷却，冷却结束仍须显式重试。最终失败也不因重入自动重试。

## 分类与计数口径

分类角色由**位置与合法层级关系**决定，不是标签集合包含关系：首标签匹配主分类，第二标签仅在属于该主分类时消耗为子分类，余下均为关联标签。后续标签即使与分类同名，也不能另归分类；无效第二标签仍是关联标签。

没有合法主分类才归“未分类”；缺子分类仍属于合法主分类。未分类组件的全部标签均可关联，无标签组件不贡献标签频数。计数与筛选必须共享这一口径，不能照搬原站位置计数与集合筛选的不一致。

分类只展示作者全集实际涉及的项，按平台顺序，搜索不移除临时无匹配的分类。分类计数固定基于作者全集；关联标签计数固定基于所选分类全集，每组件对同标签只计一次，按频数降序、同频保持原相对顺序。搜索与勾选不改变这些数字或顺序。

固定频数与动态可用性不是同一个量：未选标签若与当前搜索及已选标签组合后必无结果，禁用；已选标签始终可取消。未选分类不提供关联标签区；分类全局单选，关联标签多选 AND，与搜索取交集。

切分类或重置分类清关联标签，保留搜索与排序。点击已选卡片分类等同重置；点击未选关联标签切到该卡片合法子分类、否则主分类、否则未分类，并用该标签替换全部关联选择；点击已选关联标签只取消它。不能统一为普通 checkbox 切换。

## 搜索、排序与呈现

搜索仅覆盖标题、格纳库简介和全部标签：按所有空白分词，每词按不区分英文大小写的字面子串匹配，全部词须命中但可分布在不同字段。不做中文分词、正则、排除词或引号短语。标题和简介用原生亮黄色标记覆盖所有命中，合并重叠／相邻区间，保留安全文本与链接；标签命中任一搜索词时整枚使用原生蓝底白字，不在标签内插入黄色标记。搜索命中与筛选选中可共同点亮标签，但搜索命中不改变选中状态，清除任一条件不抹掉另一条件仍需的高亮。

IME 组词期间不应用搜索，开始组词须清掉旧挂起输入任务；非组词 Enter 立即应用，Escape 只清搜索。零结果保留条件，搜索、筛选、卡片标签点击及排序均不主动滚动。

排序默认热门程度降序，各指标独立记方向。平局保留**排序前**的相对顺序，不加 ID 等兜底，也不整体 reverse；对应缺值始终后置。热门程度是平台人数，不能由本地启停推算或因动作完成触发重排。

桌面沿用格纳库双列基线，窄屏搜索／分类先于列表，排序栏只占列表列；不套用帖子单列尺寸。不增分页、结果计数、额外二级导航、分类折叠或视图模式切换。原生 CSS 与必要适配的证据留在外部文档，真实视觉结果仍须人工验收。

排序移动既有卡片，筛选改变可见性，高亮不重建启停按钮；普通详情链接保留中键与组合键行为。作者空集合与筛选空结果必须区分，后者不能清掉筛选条件。

## 查看者启停及已接受风险

动作改变的是当前登录查看者的启用状态，与作者无关。无确认弹窗；只阻止同组件重复提交，不阻塞其他卡片或筛选。在途状态属于会话与组件，不能因卡片隐藏、排序或离开视图丢失。

成功只按原站 `response.ok` 判定，不核验登录跳转、正文或业务状态，不额外读取格纳库核实；成功更新按钮与对应动作方向，不改平台启用人数。这意味着 HTTP 成功可能并非业务成功，是产品有意接受的局限。

动作超时 15 秒，**不自动重试**。失败／超时只在按钮内显示红字“出错了”，2 秒后恢复原文字与颜色，不增加弹窗或错误区域。结果不确定时仍恢复原方向供手动再试，晚于超时的响应不得再次覆盖结算状态。

恢复原按钮不证明服务端未执行，取消等待也不能撤销已送达动作；不能套用读取重试策略。具体 AJAX 参数与线上行为尚需人工授权验证，静态脚本与本地 mock 不能证明真实协议已成立。
